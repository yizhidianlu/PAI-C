## What's new

### New SKILLs (5)

| SKILL | What it does | Trigger |
|---|---|---|
| `/paic-integrity` | 5-type citation hallucination check (TF/PAC/IH/PH/SH via S2 batch + WebSearch) + 7-mode AI failure checklist (modes 1/3/5/6 mandatory, 2/4/7 advisory). Stage 6 / Stage 9 truthfulness gate, complementary to `/paic-finalize`'s 9-class structural gate. | "integrity check" / "反引文幻觉" / "100% verify cite" |
| `/paic-revision-coach` | Parses unstructured external reviewer comments (emails / PDFs / multi-reviewer blocks) into a prioritized RevisionTask queue. 6-step pipeline: parse → classify → section-map → priority → patch_hint → output. | "审稿意见" / "R&R" / "reviewer comments" / "收到审稿" |
| `/paic-format-convert` | Pandoc-driven LaTeX/Markdown/DOCX/PDF + 5-style citation conversion (APA 7 / Chicago / MLA / IEEE / Vancouver via CSL). Pandoc graceful-degrades when missing. | "convert to LaTeX" / "convert to docx" / "改 APA 引用" |
| `/paic-disclosure` | Venue-specific AI usage disclosure paragraph render. 6 venues (ICLR / NeurIPS / Nature / Science / ACL / EMNLP) + generic fallback. RAISE-framework fields. Pure template render, no LLM. | "AI disclosure" / "投稿合规声明" / "AI 声明 [venue]" |
| `/paic-pipeline` | 11-stage end-to-end orchestrator: init → search+ingest → ideate → experiment → plan → draft → integrity-pre → review → revise → integrity-final → finalize. 3 MANDATORY checkpoints (6 / 9 / 10) cannot be auto-skipped. | "from research to draft" / "端到端 paper" / "跑一遍完整 pipeline" |

## New configuration knobs

### `~/.paic/config.yaml`

```yaml
# Material Passport — opt-in cross-session resume (default off)
passport:
  enable_reset_boundary: true       # default false
  lock_timeout_sec: 30              # default 30; ARS spec hard ceiling 60

# LLM routing — new node tags for 4-call compose
routing:
  default: anthropic
  cross_model_evaluator: false      # P2-3: when true, advise compose_v2 to
                                     # use a different backend for evaluator phases
  overrides:
    integrity_judge: host            # P0-1: WebSearch + AI judge via main conversation
    revision_parse_external: host    # P0-2: external reviewer comments via main conversation
    # Per-phase compose_v2 routing (optional — for cross-model verification)
    compose_writer_plan: anthropic
    compose_writer_exec: anthropic
    compose_evaluator_setup: openai
    compose_evaluator_exec: openai
```

## Pipeline state files

V1.0 introduces two new files under `<project>/.paic/state/`:

| File | Purpose | Schema |
|---|---|---|
| `pipeline.yaml` | 11-stage orchestrator state (current_stage, mode, consecutive_continues, stage_history) | `PipelineState` |
| `passport.yaml` | Append-only stage-boundary ledger (kind: boundary / resume + 12-char SHA-256 hash) | multi-doc YAML stream of `PassportEntry` |
| `passport.lock` | Cross-platform advisory file lock (auto-managed, never edit) | (binary) |
| `integrity_cache.json` | S2 batch verify cache keyed on (cite_key, sha256(normalized_title)) | JSON dict |
| `integrity_report.yaml` | Latest integrity gate run output | `IntegrityResult` |

All paths are added to `ProjectPaths` and tools auto-create on first
write.

  use jupyter)

## Migration

V1.0 is fully backward compatible with v0.1:
- Old `.paic/` yaml schemas unchanged
- All v0.1 SKILLs / MCP tools still work
- `/paic-draft compose` (v0.3) is the fallback when you don't want the
  4-call cost; `/paic-draft compose-v2` (v0.4) is the new strict path
- Material Passport is opt-in (default off) — projects that don't
  enable it never see passport.yaml created

To enable the V1.0 features:

```yaml
# ~/.paic/config.yaml
passport:
  enable_reset_boundary: true   # if you want cross-session resume
```

That's it — the new SKILLs are auto-discovered by Claude Code from
`skills/` and the new MCP tools are auto-registered when you restart
the MCP server (after `pip install -e .` or equivalent).
